# Poe Trade Plus Companion

Poe Trade Plus is a browser extension that adds a companion sidebar and trading utilities to the official Path of Exile trade site.

## Features

- Save and organize trade searches with folders and bookmarks.
- Revisit previous searches through a separate history for Path of Exile 1 and 2.
- Enhance results with price equivalents, stat highlights, quick filters, socket warnings, and pinned items.
- Customize the sidebar, popup shortcuts, interface language, and text size.
- Support Path of Exile 1 and 2, localized trade sites, and 11 interface languages.

## Get the extension

- [Chrome Web Store](https://chromewebstore.google.com/detail/poe-trade-plus/igofmcebdienfacijkhdppcfiglcbffb)
- [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/poe-trade-plus/)

## Privacy

Poe Trade Plus has no account system, analytics, tracking, or application-owned data server. Data is kept in browser storage; when browser Sync is enabled, supported bookmarks and settings use the browser's built-in Sync service. Optional external requests support price information and enabled trade features.
